# Vite Minimal Example

The quickest way to see ruio in action with Vite + React.

## What This Example Shows

A minimal Vite setup with:

- Single welcome component
- Basic ruio integration
- Quick start instructions

## Structure

```
App
└── Welcome
    ├── Title
    ├── Instructions (ordered list)
    └── Tip Box
```

## How to Use

1. Run the dev server:

   ```bash
   npm run dev
   ```

2. Open http://localhost:5173

3. Follow the on-screen instructions to try ruio

## Key Concepts

- **RuioWrapper**: Wraps your app to enable ruio functionality
- **Toggle Button**: Appears automatically in development mode
- **Element Selection**: Click elements to make them the new root
- **Depth Control**: Adjust to see deeper into component hierarchy
